# Font2Png
Font2PNG — это мобильный генератор текстовых ассетов для Android, позволяющий создавать стилизованные PNG-надписи с прозрачным фоном, градиентами и обводкой. Инструмент ориентирован на инди-разработчиков и дизайнеров, обеспечивая быстрый экспорт элементов UI, заголовков и пиксельных текстур для игровых движков. Полное описание доступно в RuStore.

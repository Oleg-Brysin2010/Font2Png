# Font2PNG Pro 🔤➡️🖼️

**Font2PNG Pro** — мощный мобильный генератор текстовых ассетов (плашки, логотипы) для игр и дизайна, созданный специально для работы с HTML5 Canvas в гибридной среде.

[![Доступно в RuStore](https://shields.io)](https://www.rustore.ru/catalog/app/com.dev.font2png)

---

## ✨ Основные функции

*   **Работа со шрифтами:** Поддержка кастомных `.ttf` файлов.
*   **Стилизация:** Регулировка размера, интервалов, наклона, теней, обводки и градиентов.
*   **Ретро-эффекты:** Генерация пиксельных текстур и шума (Pixel Art/Synthwave).
*   **Экспорт:** Сохранение в PNG с прозрачным фоном.
*   **Пресеты:** Система сохранения настроек стилей.

---

## 🛠️ Стек технологий (Hybrid App)

Приложение основано на веб-технологиях:
*   **UI/Core:** HTML5, CSS3, JavaScript.
*   **Графика:** HTML5 Canvas API.
*   **Платформа:** Android (6.0+).
